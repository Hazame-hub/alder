# CLA signatures

This branch stores nothing but the record of who has signed the
[Contributor Licence Agreement](https://github.com/Hazame-hub/alder/blob/main/CLA.md).

It is written by the CLA check on pull requests. Keeping it in git rather than
in a third-party service means who agreed to what, and when, is auditable with
`git log`. It is intentionally an orphan branch: it shares no history with the
code and must not be merged into `main`.

Do not protect this branch — the CLA action needs to commit to it.
